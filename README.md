# เว็บนำเสนอข้อมูลโรงเรียนสันทรายวิทยาคม
### เพื่อรับรางวัลพระราชทาน ระดับมัธยมศึกษาขนาดใหญ่ ปีการศึกษา 2569

เว็บแอปพลิเคชัน Angular (Standalone Components) นำเสนอข้อมูลด้านที่ 1–5
ตามแบบประเมินสถานศึกษาเพื่อรับรางวัลพระราชทาน — ออกแบบให้กรรมการดูบน **iPad** เป็นหลัก

---

## เปิดดูทันที (ไม่ต้องติดตั้งอะไรเลย)

เปิดไฟล์ **`preview.html`** ด้วย Safari บน iPad หรือเบราว์เซอร์ใดก็ได้
ไฟล์นี้รวมทุกอย่างไว้ในไฟล์เดียว (เนื้อหา กราฟ แอนิเมชัน) และใช้ **ข้อมูลชุดเดียวกัน**
กับแอป Angular คือไฟล์ใน `src/app/data/`

> เคล็ดลับสำหรับ iPad: เปิด `preview.html` ใน Safari แล้วกด **แชร์ → เพิ่มไปยังหน้าจอโฮม**
> จะได้ไอคอนเปิดแบบเต็มจอ ไม่มีแถบเบราว์เซอร์รบกวนตอนนำเสนอ

สร้างไฟล์นี้ใหม่หลังแก้ข้อมูล:

```bash
npm run preview      # หรือ  node tools/build-preview.mjs
```

---

## รันเป็นแอป Angular

```bash
npm install
npm start            # เปิด http://localhost:4200
npm run build        # สร้างไฟล์สำหรับขึ้นเซิร์ฟเวอร์ที่ dist/
```

ต้องมี Node.js เวอร์ชัน 18 ขึ้นไป

## โครงสร้างโฟลเดอร์

แต่ละ component แยกเป็น **3 ไฟล์** ตามมาตรฐาน Angular CLI คือ
`.ts` (ตรรกะ) · `.html` (หน้าตา) · `.css` (สไตล์เฉพาะของ component นั้น)

```

│
├── src/
│   ├── index.html                  ← meta สำหรับ iPad (viewport-fit, safe area, เต็มจอ)
│   ├── main.ts
│   ├── styles.css                  ← ระบบดีไซน์ส่วนกลาง (ตัวแปรสี โครงหน้า การ์ด ตาราง)
│   │
│   └── app/
│       ├── app.component.ts / .html / .css      ← โครงหน้าหลัก + ปุ่มกลับขึ้นบน
│       ├── app.config.ts                        ← ตั้งค่า router
│       ├── app.routes.ts                        ← เส้นทางแต่ละด้าน (โหลดแบบ lazy)
│       │
│       ├── core/
│       │   └── models.ts           ← ชนิดข้อมูลที่ใช้ร่วมกัน + จานสีกราฟ
│       │
│       ├── data/                   ★ แก้ข้อมูลที่นี่ — แยกเป็นด้าน ๆ
│       │   ├── school.data.ts      ← ข้อมูลพื้นฐาน วิสัยทัศน์ พันธกิจ เมนู BANCHUEN Model
│       │   ├── dimension1.data.ts  ← ด้านที่ 1 คุณภาพนักเรียน (ข้อมูลสถิติทั้งหมด)

│       │   ├── dimension4.data.ts  ← ด้านที่ 4 การจัดการเรียนรู้ที่เน้นผู้เรียนเป็นสำคัญ
│       │   ├── dimension5.data.ts  ← ด้านที่ 5 ความดีเด่นของสถานศึกษา

│       ├── pages/                  ★ หนึ่งหน้าต่อหนึ่งด้าน
│       │   ├── home/               home.component.ts / .html / .css
│       │   ├── awards/             หน้ารางวัลเชิงประจักษ์ (นักเรียน + ครู)
```

### CSS อยู่ตรงไหน

| ต้องการแก้ | ไปที่ |
|---|---|
| สีประจำโรงเรียน ระยะห่าง เงา | `src/styles.css` ที่บล็อก `:root` |
| การ์ด ตาราง ปุ่ม ป้ายกำกับ (ใช้ร่วมกันทุกหน้า) | `src/styles.css` |
| แถบนำทางด้านบน | `shared/navbar/navbar.component.css` |
| ส่วนเปิดหน้าแรก · การ์ดสรุป 5 ด้าน | `pages/home/home.component.css` |
| กราฟเส้น / กราฟแท่ง / แถบเปรียบเทียบ | `shared/<ชื่อกราฟ>/<ชื่อกราฟ>.component.css` |
| วงจรการดำเนินงาน 4 ขั้น | `shared/cycle-flow/cycle-flow.component.css` |
| การ์ดตัวเลขสถิติ | `shared/kpi-grid/kpi-grid.component.css` |

CSS ในไฟล์ของ component จะถูก Angular จำกัดขอบเขตให้ใช้เฉพาะ template ของ
component นั้นโดยอัตโนมัติ จึงแก้ได้โดยไม่ต้องกลัวกระทบส่วนอื่น

## วิธีแก้ไขข้อมูล

ข้อมูลทั้งหมดอยู่ใน `src/app/data/` แยกตามด้าน แก้ไฟล์เดียวก็เปลี่ยนทั้งหน้า
ไม่ต้องแตะโค้ดของหน้าเลย

**ตัวอย่าง: แก้คะแนน O-NET ชั้น ม.6**

เปิด `src/app/data/dimension1.data.ts` แล้วแก้ตัวเลขในบล็อกนี้

```ts
m6: {
  years: ['2566', '2567', '2568'],
  subjects: [
    { name: 'ภาษาไทย', school: [45.23, 47.41, 43.73], nation: [40.78, 42.21, 40.32] },
    ...
  ],
  conclusion: 'ข้อความสรุปใต้กราฟ...'
}
```

กราฟเส้น ตาราง และค่าส่วนต่าง (+/−) จะคำนวณใหม่ให้เองทั้งหมด

**ตัวอย่าง: เพิ่มขั้นตอนในวงจรการดำเนินงาน**

ทุกด้านมีโครงสร้าง `cycle` แบบเดียวกัน 4 ขั้น (วางแผน → ดำเนินการ → ตรวจสอบ → พัฒนาต่อยอด)

```ts
cycle: [
  {
    step: 'ขั้นวางแผน',
    title: 'หัวข้อของขั้นตอน',
    text: 'คำอธิบายแบบย่อหน้า',
    bullets: ['รายการย่อย 1', 'รายการย่อย 2']
  },
  ...
]
```

**ตัวอย่าง: แก้หน้าตา**

หน้าตาอยู่ในไฟล์ `.html` ของแต่ละ component เช่นอยากเพิ่มหัวข้อในหน้าด้านที่ 3
ให้แก้ `src/app/pages/dimension3/dimension3.component.html` ได้เลย

หลังแก้เสร็จ ให้รัน `npm run preview` เพื่อสร้าง `preview.html` ใหม่ (หรือ `npm start` ถ้ารัน Angular อยู่แล้ว)

## หน้ารางวัลเชิงประจักษ์

เมนู **รางวัล** บนแถบนำทางจะเปิดหน้ารวมรางวัลของนักเรียนและครู

| ส่วน | ที่มา | จำนวน |
|---|---|---|
| รางวัลนักเรียน | ภาคผนวก "รางวัลเชิงประจักษ์" เล่มด้านที่ 1 หน้า 170–190 | 36 รางวัล |
| รางวัลครู | เล่มด้านที่ 3 หัวข้อ 3.1 ข้อ 5 การสร้างขวัญกำลังใจ หน้า 61–62 | 4 รายการ |

รางวัลนักเรียน **เก็บเฉพาะรายการที่มีภาพหลักฐานอยู่ในเล่ม** ตามที่กำหนดไว้
โดยจับคู่รูปกับชื่อจากตำแหน่งจริงบนหน้ากระดาษ ไม่ได้เดาจากลำดับ

- กรองได้ตามระดับรางวัล (นานาชาติ / ชาติ / ภูมิภาค) และหมวดหมู่ 8 หมวด
- แตะรูปเพื่อดูขนาดเต็ม
- รูปทั้งหมดอยู่ที่ `public/awards/students/` และ `public/awards/teachers/`
  เปลี่ยนรูปได้โดยวางไฟล์ทับชื่อเดิม หรือแก้เส้นทางในไฟล์ `awards.data.ts`

> หมายเหตุสำหรับไฟล์ `preview.html` — หน้ารางวัลต้องใช้รูปจากโฟลเดอร์ `public`
> ถ้าจะคัดลอกไปเปิดบน iPad ให้เอา **โฟลเดอร์ `public` ไปด้วย** วางไว้ข้าง ๆ กัน
> (หน้าอื่นเปิดได้ตามปกติแม้ไม่มีโฟลเดอร์นี้)

## การออกแบบสำหรับ iPad

| ประเด็น | วิธีจัดการ |
|---|---|
| ขนาดจอ | ปรับ layout ที่ 1180px (iPad Pro), 1024px (แนวนอน), 834px (แนวตั้ง) และ 560px |
| แถบนำทาง | ตรึงด้านบนเสมอ · ยุบเป็นปุ่มเมนูเมื่อจอแคบกว่า 1024px |
| การสัมผัส | ปุ่มและลิงก์ทุกจุดสูงอย่างน้อย 44–52px ตามเกณฑ์ของ Apple |
| ไม่พึ่ง hover | เอฟเฟกต์ hover อยู่ใน `@media (hover: hover)` และมีสถานะ `:active` สำหรับการแตะ |
| ความลื่นไหล | แอนิเมชันใช้เฉพาะ `transform` และ `opacity` เท่านั้น ไม่ทำให้ Safari กระตุก |
| ประสิทธิภาพ | `IntersectionObserver` ทำงานนอก Angular zone · แต่ละด้านโหลดแบบ lazy |
| ขอบจอ | รองรับ `safe-area-inset` และ `viewport-fit=cover` |
| ตารางกว้าง | เลื่อนแนวนอนได้ภายในกรอบของตัวเอง หน้าเว็บไม่เลื่อนตาม |
| เปิดเต็มจอ | เพิ่มไปยังหน้าจอโฮมแล้วเปิดแบบไม่มีแถบเบราว์เซอร์ |
| ลดการเคลื่อนไหว | เคารพการตั้งค่า “ลดการเคลื่อนไหว” ของ iPadOS |
| พิมพ์เอกสาร | มี print stylesheet สำหรับสั่งพิมพ์เป็น PDF |

## สีประจำโรงเรียน

น้ำเงิน–ขาว โดยมีสีทองเป็นสีเน้นสำหรับรางวัลและตัวเลขสำคัญ

| ตัวแปร | ค่าสี | การใช้งาน |
|---|---|---|
| `--navy-900` | `#0d2149` | หัวเรื่อง พื้นหลังส่วนเปิด |
| `--navy-800` | `#132f63` | หัวตาราง ตัวเลขสถิติ |
| `--navy-600` | `#1e4d9e` | ปุ่ม เมนูที่เลือก เส้นกราฟหลัก |
| `--gold-500` | `#d4a537` | เส้นคั่น ปุ่มหลัก ป้ายรางวัล |
| `--paper` | `#ffffff` | พื้นหลังการ์ด |

แก้สีได้ที่ `:root` ในไฟล์ `src/styles.css` (และใน `tailwind.config.js` ถ้าใช้ utility class ของ Tailwind)
